---
name: gsa-review-lessons
description: Review GSA lessons when the user requests it or ten new lessons accumulated; propose changes to harness checks without automatically changing permissions or policy.
---
Read relevant lessons, group repeated root causes and count recurrence.
For repeated errors, propose the smallest script/checklist/skill change and maintenance cost.
Reuse available skills instead of creating duplicates.
State paths, permissions, valid/invalid tests and rollback for each proposed change.
User approval is required before installing external plugins/MCP or changing role, hook,
permissions or push policy. Existing explicit task authorization still applies.
After approved changes, test valid and invalid fixture cases plus existing harness tests.
Do not change product goal, criteria or milestones as part of lesson consolidation.
