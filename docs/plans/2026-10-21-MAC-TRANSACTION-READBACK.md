# MCP file transaction readback implementation plan — 2026-10-21

**Goal:** expose the accepted native recovery adapter's explicit observation-only readback through one bounded MCP tool.
**Architecture:** catalog → existing controller wrapper → optional `nativeFiles.recoverableMutations.readTransaction(id)` → protected journal-derived authorization/native inspect. No new persistence layer, native operation, replay path or activation policy.
**Tech stack:** existing TypeScript ESM/Node; no dependencies.
**Spec:** [adapter plan](2026-10-21-MAC-RECOVERY-ADAPTER.md), approved Mac core resumption plan and criteria §7–8 (scope, durable observations and honest results).

## Focused tests and review

- Catalog/schema: exactly transaction ID plus injected token; controlled classification; all extra path/workspace inputs rejected, including direct dispatcher calls that bypass JSON Schema.
- Capability truth: absent files, absent optional method, protected state unavailable or missing controller store keeps readback blocked; installed optional method plus storage/controller makes only readback available without claiming write/move/Git support.
- Auth: missing/wrong/expired token prevents adapter calls; valid token reaches adapter in current controller context; authorization rejection propagates without transaction metadata. Use existing disposable control-store helpers, never live state.
- Result routing: APPLIED, CONFLICT and UNKNOWN preserve the complete outcome, including opaque retained handles; the method receives only the original ID; no replace/trash/legacy mutation invocation. Unknown ID/store failure returns ordinary error without synthesizing a transaction.
- Journal-derived workspace boundary is exercised using the already accepted adapter with a disposable typed journal and fixed fake inspect transport: ID readback authorizes its stored workspace; stale/revoked binding never calls native inspect. This verifies routing/authorization, not native confinement. Reuse existing adapter evidence for duplicate lower-level cases.
